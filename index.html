WOOOOSH

An independent game inspired by daily rarity games

How to play

  1. A run is seven open prompts. You get a short look, then 25 seconds.
  2. Type one answer. The first one in the bank locks in. A miss only shakes the box.
  3. Common answers stay low. The single rarest gem on a prompt is ESCAPE. STALL is the clever pick that is not actually rare.
  4. Pass or run out of time and that prompt is zero. The other prompts still happen.
  5. Daily is the same seven prompts for everyone, dated in UTC. Open sky does not repeat a prompt until you have seen the bank, then it starts again from the oldest.
